# DS-UA 201: Causal Inference

Spring 2027 course website, adapted from the [DSC 10 course website](https://github.com/dsc-courses/dsc10-2024-su/tree/gh-pages). Built with Jekyll and Just the Docs. Run locally with `bundle install` and `bundle exec jekyll serve`. The schedule and course policies are provisional.

The site is configured for GitHub Pages at `https://ds201-causal-inference.github.io/website/`. In repository Settings → Pages, select **Deploy from a branch**, then choose `main` and `/ (root)`. Changes pushed to `main` will be published by GitHub Pages. For local development, open the `/website/` path printed by Jekyll.
