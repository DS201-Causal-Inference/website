# DS-UA 201: Causal Inference

Spring 2027 course website, adapted from the [EECS 245 course website](https://github.com/eecs245/eecs245.github.io) and the [DSC 10 course website](https://github.com/dsc-courses/dsc10-2024-su/tree/gh-pages). Built with Jekyll and Just the Docs. The schedule and course policies are provisional.

For local development, run `bundle install` and then `bundle exec jekyll serve --baseurl ''`. Open `http://127.0.0.1:4000/`. The empty base URL is needed locally because the published site lives under `/website`.

The site is configured for GitHub Pages at `https://ds201-causal-inference.github.io/website/`. In repository Settings → Pages, select **Deploy from a branch**, then choose `main` and `/ (root)`. Changes pushed to `main` will be published by GitHub Pages.
